PUBLISH ON GITHUB PAGES:
1. Extract the ZIP.
2. Upload index.html, style.css, script.js, README.txt and the pdfs folder to the repository root.
3. Inside pdfs/, create the four folders above and upload each PDF into its matching folder.
4. Open repository Settings > Pages.
5. Select Deploy from a branch, choose main and /(root), then Save.
6. Share the GitHub Pages URL with students.

Notes:
- Windows may hide the .pdf extension; the names listed here include it.
- GitHub Pages does not automatically discover PDFs. The website links are preconfigured in script.js.
- Chapter titles are based on the file names visible in your screenshots.
